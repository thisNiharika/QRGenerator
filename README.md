# ✨ QR Creator

A modern, customizable QR Code generator built with **Angular**.

Create beautifully styled QR codes in real time with full design control and logo support — fast, responsive, and easy to use.

---

## 🚀 Features

- 🔄 Live QR generation (auto updates as you edit)
- 🎨 Custom foreground & background colors
- 🔢 HEX color input support
- 🖼 Logo upload (drag & drop or file select)
- 👁 Logo preview with remove option
- 📏 Adjustable logo size
- 🔘 Optional circular logo mask
- 📐 Format selection (PNG, JPEG, SVG)
- 💾 Download generated QR code
- ✨ Smooth animations and transitions
